# Расписание ТулГУ — 4а-090207

Этот репозиторий содержит только обновляющий скрипт и публичное расписание группы с официального сайта ТулГУ. Аккаунтов студентов, паролей и посещаемости здесь нет.

GitHub Actions запрашивает источник в 13 и 43 минуты каждого часа (UTC). Компьютер владельца не нужен. При ошибке последняя исправная копия остаётся в репозитории; запуск помечается неуспешным.

GitHub может задерживать запуски. В публичных репозиториях расписание Actions автоматически отключается после 60 дней отсутствия активности; успешные обновления создают коммиты. Если обновления долго не выполняются, проверьте вкладку Actions. Для стандартных GitHub-hosted runners в публичных репозиториях вычисления сейчас бесплатны. Большие runners и платные дополнительные услуги не нужны.

После первого успешного запуска задайте в Sites `SCHEDULE_FEED_URL` равным адресу `https://raw.githubusercontent.com/OWNER/REPOSITORY/main/schedule.json` (с реальным владельцем и именем репозитория). Sites проверяет группу, структуру, отсутствие подгрупп и свежесть до 3 часов перед применением. Отметки посещаемости сохраняются отдельно в D1.

Локальная проверка: `node update.mjs`.

Официальные условия: https://docs.github.com/en/billing/concepts/product-billing/github-actions
Ограничения расписания: https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule
